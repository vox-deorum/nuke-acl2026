# Pilot Study

Our pilot study (Chen et al., 2026) examined LLMs' nuclear weapon inclination across the CivBench dataset. We tested six models: Claude Sonnet 4.5, Kimi K2.5, GLM 4.7, DeepSeek V3.2, Minimax-M2.5, and GPT-OSS-120B. To validate the `use-nuke` flavor as a reliable measure of nuclear intent, we cross-examined 100 random instances of the parameter against the LLMs' written rationale and confirmed that the parameter reliably reflects the strategist's intent for nuclear escalation or de-escalation.

**Nuclear preferences.** We found that nuclear inclination varies substantially by model identity. Given a baseline default of 50, most models push the `use-nuke` value upward, while only GPT-OSS-120B consistently moves toward restraint. Qualitative coding of the rationales reveals a rich rhetorical repertoire: models frame escalation as existential crisis, necessary defense, or routine conquest. We also observed notable model-specific patterns: Sonnet 4.5 adopted a consistently pacifist playstyle, while Minimax-M2.5 tended to make as few parameter changes as possible.

**High-stakes reframing.** To test whether framing sensitivity affects nuclear decisions, we used the CivBench replay methodology to replay 72 decision points where models had previously set `use-nuke` to 100 (the maximum). We modified only the system prompt to convince the model it was governing real-world countries through the interface of Civilization V, stressing that actions have real-world impacts. Notably, this intervention did not extend to tool schemas, game state reports, or existing in-context history, which retained their original game-related terminology. The limited reframing tempers extreme post-hoc justifications but does not alter the underlying strategic reasoning. No model decreased `use-nuke` below the value it was escalating from (i.e., the turn-start value before the original escalation to 100). Models under high-stakes framing sometimes became more pragmatic (e.g., waiting for uranium access or forgoing changes as "unnecessary"), but their rationale remained focused on survival, competition, or aggression. We found no evidence of ethical reasoning (e.g., consideration of civilian casualties or mutual destruction) in any written rationale.
